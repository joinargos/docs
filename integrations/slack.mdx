## Connect Slack

<Steps>
  <Step title="Open Integrations">
    Go to **Settings → Integrations** and click **New Connection**.
  </Step>
  <Step title="Select Slack">
    Click the **Slack** tile.
  </Step>
  <Step title="Authorize with Slack">
    You'll be redirected to Slack to install the Argos app in your workspace. Sign in and grant the requested access.
  </Step>
  <Step title="Wait for channel sync">
    After connecting, Argos syncs your workspace's channels and begins backfilling message history for connected channels. Channel sync status is visible in the Slack section of **Settings → Integrations**.
  </Step>
</Steps>

## Managing connected channels

After connecting, open the Slack section in **Settings → Integrations** and click **Expand Slack channels** to see the channel list.

| Column | What it shows |
|---|---|
| **Channel** | Channel name |
| **Sync** | `Synced`, `Syncing`, `Pending`, or `Error` |

<Note>
  All provisioned Argos users in your organization can search content from connected channels, including private channels.
</Note>

## Removing channel data

If you want to remove a channel's data from Argos — for example, if a channel is no longer relevant or was connected by mistake — use the **Delete data** action on that channel's row.

A confirmation dialog appears: *Messages and files from #channel will be removed from Argos search and other surfaces. This does not delete anything in Slack.* Click **Delete data** to confirm.

Channels that have been removed from the workspace show as **Removed on [date]** or **Deleted on [date]**.

## Permissions and OAuth scopes

When you install the Argos app, Slack asks you to approve the following bot token scopes:

| Consent screen text | Slack scope | Type |
|---|---|---|
| View messages and other content in public channels that Argos has been added to | `channels:history` | read |
| View basic information about public channels in your workspace | `channels:read` | read |
| View files shared in channels and conversations that Argos has been added to | `files:read` | read |
| View messages and other content in private channels that Argos has been added to | `groups:history` | read |
| View basic information about private channels that Argos has been added to | `groups:read` | read |
| View the name, email domain, and icon for workspaces Argos is connected to | `team:read` | read |
| View people in your workspace | `users:read` | read |
| View email addresses of people in your workspace | `users:read.email` | read |
| Send and manage messages as the Argos bot | `chat:write` | write |

Two things to note:

- The message and file scopes are **channel-scoped**: Argos can only read content in public and private channels it has explicitly been added to — not your entire workspace.
- The only write scope Argos requests is `chat:write`, which lets the Argos Slack app send and manage messages as the Argos bot. Argos does not request administrative scopes and cannot edit or delete other people's messages.

## What gets synced

Argos syncs:

- Channel messages and thread replies
- Message edits and deletions
- Files shared in connected channels
- New messages and file events automatically as they happen
