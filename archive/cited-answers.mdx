## Why citations matter

Argos doesn't summarize from memory — it searches your actual archive and cites the specific records it used. You can verify every claim by clicking through to the source.

## Citation types

Argos can cite a wide range of source types depending on what's connected and indexed:

| Citation type | What it is |
|---|---|
| Matter | A matter in your archive |
| File | An uploaded or synced document |
| Email / Email Attachment | A raw email or its attachment |
| Gmail Thread / Message / Attachment | Content from a connected Gmail mailbox |
| Outlook Thread / Message / Attachment | Content from a connected Outlook mailbox |
| Drive File | A file imported from Google Drive |
| SharePoint File | A file imported from SharePoint |
| Linear Issue / Comment | An issue or comment from connected Linear |
| Slack Message / File | A message or file from a connected Slack channel |
| Activity | Activity recorded on a matter |

## Reading inline citations

Citation badges appear inline in the answer text. Each badge identifies the source type (for example, `Gmail Thread` or `File`). Click a badge to open the source detail.

## The citations table

Below the answer, a table lists all cited sources with **Source** and **Type** columns. Click any row to navigate to that source in Argos.

For file citations, Argos can link to a specific page, block, or location within the document where the relevant passage appears.

For Slack citations, some entries include a direct link to the original message in Slack.

## When an answer has no citations

If Argos can't find relevant material in your archive for a question, it will say so rather than fabricating an answer. Try rephrasing or broadening the question, or check that the relevant integration is connected and synced.
